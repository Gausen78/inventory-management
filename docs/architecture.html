Factory Inventory Management System

A full-stack demo application for inventory management, order tracking, demand forecasting, and spending analytics. A Vue 3 single-page app talks to a Python FastAPI service that serves in-memory mock data loaded from JSON files — no database.

1System Architecture

Three logical tiers. The browser runs the Vue SPA; all dynamic data is fetched over HTTP/REST from the FastAPI service, which filters and validates in-memory datasets loaded once at startup.

3Data Flow

A typical request: a user changes a filter, the SPA re-fetches, and the backend filters and validates in-memory data before returning JSON the view renders through computed properties.

01

User interaction

FilterBar.vue updates shared filter state in useFilters (period, warehouse, category, status).

→
02

API client

api.js builds query params via Axios — values equal to all are omitted.

→
03

HTTP request

GET /api/... hits FastAPI on port 8001 (CORS open in dev).

→
04

Filter + validate

Handler runs apply_filters() / filter_by_month() over in-memory lists; Pydantic validates the response.

→
05

Render

JSON lands in Vue refs; computed properties derive metrics and feed SVG charts & tables.

Filter system. Four global filters apply across views — Time Period, Warehouse, Category, and Order Status. State lives in a single shared useFilters composable (singleton refs). Time Period maps to a month param and supports both direct months (2025-09) and quarters (Q1-2025). Inventory has no time dimension, so it ignores the period filter.
